# 05 · 运行部署与配置

## 1. 构建

```bash
# 要求：JDK 8 + Maven 3.x
cd wone-standalone-site
mvn clean package -DskipTests
# 产出：target/wone-standalone-site.jar（spring-boot repackage，可执行）
```

> 主类：`com.rockwill.deploy.StandAloneSiteApplication`（`spring-boot-maven-plugin` 配置）。

---

## 2. 本地运行

```bash
# 方式一：直接跑 jar
java -jar target/wone-standalone-site.jar

# 方式二：Spring Boot 插件
mvn spring-boot:run
```

- 默认端口 **9080**（`server.port`）。
- 启动后（`brand.execute-on-start=true`）会：拷贝静态资源 → 预热菜单 → 对 `brand.execute-on-domain` 执行全量生成。
- 若 CMS（`192.168.35.16`）不可达，启动生成会失败但应用仍可启动（异常被 catch 记日志）。

---

## 3. 配置项（`application.yml` 关键项）

```yaml
server:
  port: 9080
wcm-api: http://192.168.35.16/wcm-api/site/static/   # CMS 基地址
brand:
  languages: en,fr,...        # 支持语言（60+）
  mapLang: en_US,fr_FR,...    # 含地区后缀（SEO/面包屑修正用）
  domain: www.test-static.com # 主域名
  static-output: ./static-output   # 静态输出（= Nginx root）
  request-log-dir: ./request-logs
  scheduler-enable: true
  cron: "0 0 6 */3 * ?"      # 每 3 天 06:00 全量生成
  execute-on-start: true
  execute-on-domain: www.test-static.com
  domain-list: []            # 其余多站点域名
  secret: <md5 签名密钥>      # 与 CMS 侧一致
  caseTranslateOnline: false
cdn:
  enabled: true
  prefix: "https://oss.iee-business.com"
  version: 1.1.5
google-tag:
  id: G-0HKGZJNMN6
  domains: { www.rockwill.com: G-..., ... }
cloudflare:
  api-url: https://api.cloudflare.com/client/v4/zones
  domains:
    "[www.rockwill.com]": { zone-id: xxx, api-token: xxx }
```

> 多环境：默认 `spring.profiles.active=prod`（`RockwillKnowledgeService.devMode`），可加 `application-<profile>.yml` 覆盖。

## 4. Nginx 部署（`nginx/server.conf`）

```nginx
server {
    listen 80;
    server_name  www.test-static.com;
    index index.html;
    root  <项目>/static-output/;

    # 静态资源（css/js/img…）独立 alias
    location ~* \.(css|js|png|...)$ {
        alias <项目>/static-output/static/;
        try_files $uri =404;
    }
    # 页面：先找静态文件，找不到回源
    location / {
        try_files $uri $uri/index.html @api_backend;
    }
    location @api_backend {
        proxy_pass http://localhost:8080;   # ⚠️ 见下方注意
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

> ⚠️ **端口注意**：Nginx `proxy_pass` 为 `:8080`，应用实际监听 `:9080`。生产环境通常由前置 LB 补齐端口；本地联调需确保一致，否则实时回源会 502。

## 5. 触发静态化的三种方式

| 方式 | 触发 | 说明 |
| --- | --- | --- |
| 启动生成 | `brand.execute-on-start=true` | `AppStartListener` 启动时对 `execute-on-domain` 全量生成 |
| 定时生成 | `StaticPageScheduler` cron | 每 3 天对主域名 + `domain-list` 全量生成 |
| 手动触发 | `POST /api/staticize/trigger`（需签名） | 全量或按 `prodIds/articleIds/caseIds/newsIds` 增量 |
| 内容同步 | `POST /api/staticize/sync`（需签名） | CMS 变更 → 删文件 + Cloudflare 清理 |

### 手动触发示例（签名略）

```http
POST /api/staticize/trigger
Content-Type: application/x-www-form-urlencoded

appId=xxx&timestamp=...&nonce=...&signature=...&data={"domain":"www.test-static.com","prodIds":"101,102"}
```

### 签名算法（`ApiSignatureInterceptor`）

```
stringToSign = 排序(appId,timestamp,nonce,data) 以 & 连接 + "&secret=" + secret
signature    = MD5(stringToSign).toUpperCase()
```
- 时效：请求 `timestamp` 与服务器时间差 ≤ 5 分钟。
- 频率：`/trigger` 限制 1 次/小时、5 次/天（按 `appId`）；`/sync` 豁免。

## 6. 输出目录结构（`static-output/`）

```
static-output/
├── index.html              # 主域名首页
├── 404.html
├── robots.txt
├── sitemap.xml (+ sitemap_1.xml … 分块)
├── static/                 # 拷贝的 css/js/img 资源
├── products/
│   ├── index.html          # 列表第 1 页
│   ├── products-2/index.html
│   └── detail/xxx-123/index.html
├── <lang>/                 # 各语言版本（en/, fr/…）
└── <other-domain>/         # domain-list 多站各自子目录
```

## 7. 监控与日志

- 应用日志：`logging.level.com.rockwill=info`，`logs/`（logback.xml）。
- 请求日志（留言/上传）：`request-logs/<domain>/<yyyyMMdd>/<leaveMsg|uploads>/<requestId>/request.json`。
- CMS 访问状态回写：`/publish/updateState`（生成成功 state=2，失败 state=3 + reason）。

## 8. 常见运维动作

| 场景 | 操作 |
| --- | --- |
| 全站重建 | `POST /api/staticize/trigger`（data 仅含 domain）或等待定时任务 |
| 单篇内容更新 | CMS 推 `POST /api/staticize/sync`（携带 entityType/entityId），自动删文件 + 清 CDN |
| 新增语言/站点 | 改 `brand.languages` / `brand.domain-list` → 重启 → 触发全量 |
| CDN 不刷新 | 检查 `cloudflare.domains[<domain>].zone-id/api-token` 是否配置 |
| 实时回源 404 | 查 `UnifiedRouterController` 日志 + CMS 可达性；非法路径会被重定向首页 |
