## 1. `StaticPageService` — 静态化核心引擎
`service/StaticPageService.java` · 83 符号

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `triggerGenPages` | `@Async generateAllPages(domain, Map<Integer,Set<Long>>)` | 异步增量生成入口（被 `StaticizeTriggerController.triggerStaticization` 调用）。拷贝资源 → 首页 → 预热菜单 → `generateMenuAndDetailPage`。完成后回写发布状态（`/publish/updateState`）。 |
| `generateAllPages` | `void generateAllPages(domain)` | **全量生成**。默认语言 + 各语言遍历；末了生成 sitemap + robots。调用方：`AppStartListener`、`StaticPageScheduler`。 |
| `generateIndexPage` | `void generateIndexPage(domain)` | 生成首页 `index.html` 与 `404.html`，写入 sitemap（优先级 1.0）。 |
| `generateMenuAndDetailPage` | `void(lang, domain, updatedIdsByType)` | 遍历 `SiteMenuUtils.getMenuPages()`：拉列表页 → 存盘 → 处理分页 → 处理分类 → 处理详情；增量模式跳过无更新的类型。 |
| `processPagination` | `List<CompletableFuture<Void>>(...)` | 按 `totalPages` 生成各分页目录，并（p≥2 时）采集详情页任务。 |
| `processMenuCategory` | `void(...)` | 处理「有分类」的栏目（Products/Documents）：遍历 `association` 分类树 + 子分类，生成分类页与分页。 |
| `processDetailPages` | `List<CompletableFuture<Void>>(...)` | **详情页核心**：用 Jsoup 按 `cssQuery` 抽取列表页中的详情链接 → 逐个渲染落盘 → 产品类额外渲染 `-series` 系列页。 |
| `saveHtml` / `deleteSavedHtml` | `void(domain, namePrefix, html)` / `void(domain, namePrefix)` | HTML 落盘 / 删除；文件名经 `sanitizeFileName` 清洗。 |
| `copyStaticResources` | `void(domain)` | 把 `classpath:/static/**` 拷贝到 `static-output/static`；`robots.txt`/`sitemap*` 复制到域名根。 |
| `addWebSitemap` | `void(html, uri, priority, domain)` | 向 `webSitemapUrls` 追加 URL（按页面类型给优先级）。 |

> **调用链（CodeGraph）**：`generateAllPages → generateIndexPage → saveHtml`；`saveHtml` 有 7 个调用点（含 `UnifiedRouterController` 实时落盘 + `StaticPageService` 内部多处）。

## 2. `RockwillKnowledgeService` — CMS 客户端 + 渲染编排
`service/RockwillKnowledgeService.java` · 88 符号（本项目最大类）

| 方法 | 说明 |
| --- | --- |
| `getSiteMenu(domain)` | GET `getMenu` → 解析 `sitePages` + `langList` → 写入 `SiteMenuUtils`（进程内缓存）。 |
| `getFromApi(RestTemplate, path, host)` | **渲染主入口**。GET `wcm-api/<path>` → 拿到 `model`(Map) → 注入 `cdnEnabled/cdnPrefix/version/gaTrackingId/brandUrl/langEName` 等 → 处理日期键、SEO Schema JSON、面包屑、成功案例链接 → 按 `templateName` 调 `renderPage` → 返回 `DomainHtmlVo`。 |
| `getHome(RestTemplate, host)` | 封装 `getFromApi(..., "home", host)`。 |
| `forwardFormRequest(req, targetUrl)` | 把留言/上传表单（含 multipart 文件）转发给 CMS；做邮箱+手机校验（leaveMessage）、写请求日志（`request-logs/<domain>/<date>/<类型>/<requestId>/request.json`）。 |
| `submitForm(targetUrl, domain, params)` | 主动发起表单 POST（如回写发布状态 `updateState`）。 |
| `getTodayUpdatedIds(domain)` | 查 CMS `publish/todayUpdatedIds`，按类型分组返回当日更新 ID（增量生成用；当前手动 trigger 改为直接解析请求体 `prodIds/articleIds/caseIds/newsIds`）。 |
| `handleSchemaJson` / `handleDateKey` / `handlePlatformSuccessCaseLink` | 渲染前的模型后处理（SEO 结构化数据、日期标准化、跨语言案例链接修正）。 |

> `languageMap` 内含 60+ 语言代码 → 英文名的映射，用于 `langEName` 注入。

## 3. `CloudflarePurgeService` — CDN 清理
`service/CloudflarePurgeService.java` · 35 符号

| 方法 | 说明 |
| --- | --- |
| `purgeByUrls(domain, urls)` | 入口：按域名取 zoneId/token → 去重 → 分批（≤100）→ 逐批 `POST purge_cache` → 批间 `sleep(purgeRequestIntervalMs)`。单批失败仅记日志、不中断。 |
| `purgeBatch(...)` | 单批请求；**同时校验 HTTP 2xx 与响应体 `success` 字段**（避免只信状态码）。 |
| `normalizeUrls` / `resolveBatchSize` / `isCloudflareSuccess` | URL 去重、批次上限强制 ≤100、响应成功判定。 |

> 内部 `SleepStrategy` 接口便于测试替换真实 sleep。

## 4. `UnifiedRouterController` — 实时回源
`controller/UnifiedRouterController.java` · 28 符号

- `routeRequest(HttpServletRequest)`：读 `X-Original-URI` → 取 `patternType` → `switch`：
  - `LEAVE_MESSAGE` / `UPLOAD` → `forwardFormRequest`
  - `MENU_WITHOUT_PAGE`（且 `/`）→ `getHome`
  - 其余（`DETAIL/SEARCH/CATEGORY_PAGINATION/...`）→ `getFromApi`
  - 默认 → 重定向首页
- 渲染后：`!realUri.startsWith("/search")` 且非 404 → `staticPageService.saveHtml(host, uri, html)` 即时落盘。

## 5. `StaticizeTriggerController` — 触发与同步
`controller/StaticizeTriggerController.java` · 41 符号

- `triggerStaticization(SecurityReq)`：`/api/staticize/trigger`。解析 `data` 中的 `prodIds/articleIds/caseIds/newsIds` → 映射为 `Map<SitePageType, Set<Long>>` → `triggerGenPages`。
- `triggerSync(SecurityReq, parsedData)`：`/api/staticize/sync`。解析 `StandaloneSyncEvent`；`DELETE` 忽略；`buildSyncContext` → `collectHomePage` / `collectPaginationPages` / `collectMainPages`（含 `collectProductPages` 处理 `-series` 与 `detail/`）→ `purgeByUrls`。
- 私有 `deleteAndRecord(file, domain, path, urlSet)`：删本地文件并把完整 URL 加入清理集合（自动补 `https://`）。

## 6. `PathMatchUtils` / `PathPatternType` — URL 路由
`utils/PathMatchUtils.java` · 38 符号

- 静态初始化 7 条正则（`SEARCH` / `LEAVE_MESSAGE` / `DETAIL` / `CATEGORY_PAGINATION` / `MULTI_LEVEL` / `CATEGORY_WITH_ID` / `MENU_WITH_PAGE` / `MENU_WITHOUT_PAGE`）。
- `matchResult(path)`：剥离语言前缀 → 正则匹配 → 提取命名分组 → 拼 `forwardTarget`（`?name=&id=&pageNum=&lang=`）→ 校验菜单名/非法多级 ID → 返回 `MatchResult`。
- 与 `PathPatternType.forwardTarget` 的映射（CMS 路径）：

| 类型 | forwardTarget |
| --- | --- |
| SEARCH | `/public/search` |
| LEAVE_MESSAGE | `/public/leaveMessage` |
| DETAIL | `/public/detail` |
| MULTI_LEVEL | `/public/url` |
| CATEGORY_PAGINATION / CATEGORY_WITH_ID | `/public/urlData` |
| MENU_WITH_PAGE / MENU_WITHOUT_PAGE | `/menu/topNavPages` |

## 7. 渲染与落盘
`render/TemplateEnginePageRenderer.java` · 38 符号

- `renderPage(templateName, variables)`：`synchronized`；构建 `WebContext`（无请求上下文时回退 Mock）→ `templateEngine.process` → 替换 `oss.iwone.cn` → 返回 HTML。
- `saveToFile(content, filePath)`：建父目录 → UTF-8 写文件。

---

## 8. 静态资源与 SEO 生成
- `SiteSitemapUtils.generateStaticSitemap(domain, urls)`：按优先级排序 → 单文件或分块（>2000 URL 生成 `sitemap_1..n` + `sitemap.xml` 索引），注入 XSL。
- `RobotsUtils.generateRobots(domain, isHttps, root)`：写 `robots.txt`，含 AI 爬虫（GPTBot/Google-Extended/ClaudeBot 等）放行/封禁规则 + `Sitemap:` 指向。
- `SiteMenuUtils`：进程内静态缓存（`menuPages` / `langList`）。

---

## 9. 安全
- `ApiSignatureInterceptor`：`appId+timestamp+nonce+data` 按 key 排序拼 `&secret=` → MD5(大写) 比对；`timeDiff>5min` 拒绝；频率限制（1 次/小时、5 次/天，用 `AccessRecord` 滑动窗口）；`/api/staticize/sync` 豁免频率限制；解析后把 `data` 的 JSON 放入 `parsedData` 属性供 Controller 使用。
- `SecurityReq` / `AccessRecord`：签名参数载体 / 频率计数。
